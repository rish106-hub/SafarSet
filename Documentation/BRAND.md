# SafarSet Brand System

## Position

SafarSet is calm operational control during travel disruption. It is not a luxury booking brand and it is not an AI flight-search toy.

## Mark

The route line folds into an `S`. The solid path signals continuity. The dashed path signals a monitored or changing journey.

## Palette

- Airspace: `#102A43`
- Navigation cyan: `#2CB1BC`
- Signal amber: `#F6AD55`
- Cloud: `#F7FAFC`
- Slate: `#52606D`

Cyan is used for movement, monitoring, and valid state. Amber is reserved for disruption and action. Red is reserved for failure.

## Typography

- Interface and display: Geist Sans.
- Timings, airport codes, statuses, and technical labels: Geist Mono.
